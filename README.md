## Application DevOps — Mini-Projet Git Collaboratif

Ce dépôt contient la structure initiale et la gestion de versions d'une application DevOps multi-modules. L'objectif de ce projet est de simuler un flux de travail collaboratif sous Git, incluant la gestion de branches, les revues de code et la résolution de conflits.

---

## 📁 Structure du Projet


devops-application/
├── src/        # Code source de l'application principal
├── tests/      # Tests unitaires et d'intégration
├── docs/       # Documentation technique du projet
├── config/     # Fichiers de configuration
└── .gitignore  # Fichiers et dossiers ignorés par Git
